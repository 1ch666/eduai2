# 證物比較介面 — 待集中驗收

court/evidence-viewer.js 已接入伺服器程序操作與庭審重播兩個面板。

實作內容：雙欄選取證物、文字關鍵字標示、證物編號、來源角色、metadata、事實 ID、伺服器採納／呈現狀態。手機窄螢幕改上下排列。重播可從證物直接篩選關聯紀錄，只查看播放位置以前的事件。

只接收嚴格 v1 snapshot 的可見證物，切換歷史版本後不可保留不再可見的選项。顯示不提交 review/present 動作，不改採納結果。無 HTML 注入、無模型呼叫、無圖片或外部 URL 抓取、無本機保存私人證物。

九類型可顯示其文字說明與類型標籤，但不等於已完成九種視覺 renderer。目前後端仍主要提供 document。assetId 只顯示缺少視覺呈現的提示，不當成網址；圖片 zoom/pan、時間線結構、Unity 世界展示／特寫及鏡頭恢復仍未完成。

依使用者要求，先集中實作、最後統一驗收。本批只有必要 JS 語法／diff 檢查，未執行瀏覽器與實機驗收，未部署。
