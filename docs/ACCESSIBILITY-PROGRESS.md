# 法庭閱讀與操作設定（實作中）

依使用者最新要求：先集中完成實作，再統一驗收。以下不等於已驗收或已部署。

## 已寫入網頁介面

- court/accessibility.js：標準／125%／150% 字級，黑白高對比，跟隨系統／減少動態效果，恢復預設。
- 僅保存上述顯示偏好於 localStorage；不保存帳號、token、場次或案件資料，不呼叫後端。
- 儲存受限時仍套用本次設定並提示；跨分頁設定同步，讀取值採白名單。
- court/index.html：鍵盤跳至主內容；court.css：焦點外框、長文字換行、觸控目標、safe area、重播清單可讀性。
- 不關閉文字對話、語音選用或現有桌機／手機遊戲操作。
